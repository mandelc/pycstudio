              Import canvas_studio as studio and call its helpers:
              studio.clear(color),
              studio.rect(x, y, width, height, fill, stroke="#000", *, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees"),
              studio.circle(x, y, radius, fill, stroke="#000", *, stroke_width=1, rotation_origin=None, rotate=None, angle_unit="degrees"),
              studio.ellipse(x, y, width, height, fill, stroke="#000", *, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees"),
              studio.arc(x, y, radius, start_angle, end_angle, stroke="#000", width=2, origin=(0, 0), rotate=None, angle_unit="degrees")
              (set angle_unit="radians" for radians),
              studio.polygon(points, fill, stroke="#000", *, stroke_width=1, x=None, y=None, origin=(0, 0), rotate=None, angle_unit="degrees"),
              studio.line(x1, y1, x2, y2, stroke="#000", width=2),
              studio.text(value, x, y, size, color, align="left", *, stroke=None, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees"),
              studio.load_image(name),
              studio.load_sound(name),
              studio.play_sound(sound),
              studio.pause_sound(sound),
              studio.stop_sound(sound), and
              studio.image(img, x, y, w, h, origin=(0, 0), rotate=None, angle_unit="degrees"). Add an
              image or sound with its toolbar button, then load it by filename.
              Use studio.stop_sound(sound) to stop playback and reset it
              to the beginning.
              studio.mouse_x and studio.mouse_y give the current
              pointer position in the canvas coordinate space. The default
              canvas size is 960 × 520; use
              studio.set_canvas_size(width, height),
              studio.get_canvas_width(), and
              studio.get_canvas_height() to change or query it.
              Use studio.translate(x, y),
              studio.rotate(angle, angle_unit="degrees"),
              and studio.scale(x, y) to transform subsequent shapes;
              set angle_unit="radians" to use radians. Call
              studio.reset_transform() to clear the transforms.
              Call studio.hide_mouse_pointer() or
              studio.show_mouse_pointer() to control the pointer while it
              is over the canvas.
              Register optional draw, update,
              setup, mousePressed,
              mouseReleased, keyPressed, and
              keyReleased callbacks with
              studio.start(draw, update=update, setup=setup, mousePressed=mousePressed, mouseReleased=mouseReleased, keyPressed=keyPressed, keyReleased=keyReleased).
              update runs before draw at the display's
              animation cadence. Read studio.button in mouse
              callbacks; its values are 0 (primary), 1 (middle), and 2
              (secondary). Keyboard state is available as studio.key,
              studio.key_code, and studio.key_code_name
              (for example,
              ShiftLeft or ShiftRight). Browser tabs
              from the same origin can exchange JSON messages with
              studio.open_channel(name, on_message). For a network
              peer connection, register a virtual service with
              studio.net_listen(port, on_connected) and connect
              with studio.connect(relay_host, virtual_port).
