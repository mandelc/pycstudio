API Reference

Python Canvas Studio library

Use these functions and callbacks in the studio’s Python editor. Coordinates and sizes are measured in canvas pixels from the top-left. Optional arguments are shown with their defaults. Entries are sorted alphabetically within each category. For shape rotation, rotation_origin=(x, y) uses normalized coordinates from (0.0, 0.0) at the unrotated top-left to (1.0, 1.0) at the bottom-right. For example, (0.5, 0.5) is the center. Values must be between 0.0 and 1.0. Provide both rotation_origin and rotate to enable per-shape rotation. Angles are clockwise and default to degrees.

Canvas and drawing

clear

clear(color="#ffffff")

Fill the entire canvas with the given color.

background

background(color)

Alias for clear(color).

rect

rect(x, y, width, height, color="#5b56e8", *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a filled rectangle beginning at its top-left corner. Use normalized coordinates for rotation_origin; (0.5, 0.5) rotates around its center.

circle

circle(x, y, radius, color="#f6c85f", *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a filled circle centered at (x, y). Use normalized coordinates for rotation_origin; (0.5, 0.5) is its center.

ellipse

ellipse(x, y, width, height, color="#f6c85f", *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a filled ellipse centered at (x, y). Use normalized coordinates for rotation_origin; (0.5, 0.5) is its center.

arc

arc(x, y, radius, start_angle, end_angle, color="#39445c", width=2, *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a stroked arc centered at (x, y). Arc angles increase clockwise. Use normalized coordinates for rotation_origin across the arc's diameter-sized bounds.

polygon

polygon(points, color="#5b56e8", *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a filled polygon from at least three (x, y) point pairs. Use normalized coordinates for rotation_origin across its bounding box.

line

line(x1, y1, x2, y2, color="#39445c", width=2)

Draw a line between the two endpoint coordinates.

text

text(value, x, y, size=20, color="#253149", *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw the string representation of value at the given position and size. Newline characters (\n) start a new line below the previous line. Use normalized coordinates for rotation_origin across the rendered text bounds.

Canvas size and transforms

set_canvas_size

set_canvas_size(width, height)

Set the canvas pixel dimensions. Both values must be positive integers.

get_canvas_width

get_canvas_width()

Return the current canvas width in pixels.

get_canvas_height

get_canvas_height()

Return the current canvas height in pixels.

translate

translate(x, y)

Move the origin for subsequent drawing operations by the given offset. Combine with rotate() and scale() to transform a group of shapes with one shared transform; this avoids setting up a separate rotation for each shape. Use reset_transform() afterward to restore the default transform.

rotate

rotate(angle, angle_unit="degrees")

Rotate subsequent drawing clockwise. The angle unit may be "degrees" or "radians". For a group of shapes that share an angle and pivot, apply the rotation once with translate() and draw the shapes under that shared transform instead of passing rotation_origin and rotate to every shape.

scale

scale(x, y=None)

Scale subsequent drawing horizontally by x and vertically by y. If y is omitted, both axes use x. Scaling, like translation and rotation, remains in effect for following shapes until reset_transform(); combine transforms once when drawing a group that shares them.

reset_transform

reset_transform()

Reset translation, rotation, and scaling to their defaults.

Images

load_image

load_image(name)

Load an image by filename from the Added Images gallery. Add the image to the project first.

image

image(image_object, x, y, w, h, *, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw a loaded image at (x, y), scaled to width w and height h. Use normalized coordinates for rotation_origin; (0.5, 0.5) is the image center.

Frame callbacks

update

update()

Optional game-logic callback, invoked before draw() on each animation frame (about every 16 ms).

draw

draw()

Optional drawing callback, invoked on each animation frame (about every 16 ms). When both callbacks exist, update() runs first.

Input callbacks and values

mousePressed

mousePressed()

Optional callback invoked when a mouse button is pressed on the canvas.

mouseReleased

mouseReleased()

Optional callback invoked when a mouse button is released on the canvas.

keyPressed

keyPressed()

Optional callback invoked once when a key is pressed while the canvas is focused. Holding a key does not repeat this callback.

keyReleased

keyReleased()

Optional callback invoked when a key is released while the canvas is focused.

mouse_x and mouse_y

mouse_x mouse_y

Current pointer coordinates in canvas pixels. The origin is at the canvas’s top-left.

key

key

String value of the most recent keyboard event, such as "Enter" or "a".

key_code

key_code

Numeric key code for the most recent keyboard event; Enter is typically 13.

key_code_name

key_code_name

Physical key identifier, such as "ShiftLeft" or "ShiftRight".

Example

set_canvas_size(800, 500)
player_x = 400

def update():
    global player_x
    if key == "ArrowLeft":
        player_x -= 4
    if key == "ArrowRight":
        player_x += 4

def draw():
    clear("#ffffff")
    circle(player_x, 250, 24, "#5b56e8")
