              Drawing helpers: clear(color), rect(x, y, w, h, color),
              circle(x, y, radius, color),
              ellipse(x, y, width, height, color),
              arc(x, y, radius, start_angle, end_angle, color, width, angle_unit="degrees")
              (set angle_unit="radians" for radians),
              polygon(points, color),
              line(x1, y1, x2, y2, color, width),
              text(value, x, y, size, color),
              load_image(name), and
              image(img, x, y, w, h). Add an
              image with the Add Image button, then load it by filename.
              mouse_x and mouse_y give the current
              pointer position in the canvas coordinate space. The default
              canvas size is 960 × 520; use
              set_canvas_size(width, height),
              get_canvas_width(), and
              get_canvas_height() to change or query it.
              Use translate(x, y),
              rotate(angle, angle_unit="degrees"),
              and scale(x, y) to transform subsequent shapes;
              set angle_unit="radians" to use radians. Call
              reset_transform() to clear the transforms.
              Define update() for game logic and
              draw() for rendering; both run every 16 ms, with
              update() first. Without either, the program runs once and finishes.
              Define mousePressed() or mouseReleased()
              to handle mouse buttons pressed or released inside the canvas;
              define keyPressed() or keyReleased()
              to handle keyboard input while the canvas is focused. The latest
              key is available as key and its numeric key code
              (for example, Enter is 13) as key_code. The physical
              key name is key_code_name (for example,
              ShiftLeft or ShiftRight).
