API Reference

Python Canvas Studio library

Import the browser-provided library with import canvas_studio as studio, then call drawing and utility functions as studio.function_name(...). Register optional lifecycle and input callbacks with studio.start(); read input values such as studio.key from the module. Use these APIs in the studio’s Python editor or with the standalone desktop module. For desktop use, install python -m pip install -r requirements-desktop.txt and run a Python file from this folder. The desktop studio.start() owns the Pygame event loop and returns when its window closes. Asset paths may be bare filenames or paths under images/ and sounds/; exported desktop projects resolve those folders alongside the module even when run from another working directory. The studio’s Export ZIP includes the project, desktop module, dependency list, message server, and any added image or sound assets. Existing programs that use the former global helpers and callback names remain supported for compatibility. Coordinates and sizes are measured in canvas pixels from the top-left. Optional arguments are shown with their defaults. Entries are sorted alphabetically within each category. For the shape helpers other than circle(), origin=(x, y) is a normalized position from (0.0, 0.0) at the bounds' top-left to (1.0, 1.0) at the bottom-right. When set on a helper with x, y arguments, that point in the shape is placed at (x, y); if rotate is also set, it rotates around that same point. The default is (0, 0) (the top-left). Values must be between 0.0 and 1.0. circle() retains its rotation_origin rotation-only argument. Angles are clockwise and default to degrees.

Starting a program

start

studio.start(draw=None, *, update=None, setup=None, mousePressed=None, mouseReleased=None, keyPressed=None, keyReleased=None)

Register callbacks after defining them. setup runs once when start() is called. If draw or update is registered, they run every display-paced frame, with update first. Input callbacks run for their corresponding canvas events. All callbacks are optional. The browser drives its animation loop; the desktop Pygame version runs its window loop until the window closes.

init

studio.init(draw=None, *, update=None, setup=None, mousePressed=None, mouseReleased=None, keyPressed=None, keyReleased=None)

Backward-compatible alias for studio.start().

Processing-style drawing

processing_simulator

import processing_simulator as p

This helper maps a core Processing-style 2D API to canvas_studio for browser and desktop projects. It includes size(), background(), mouseX, mouseY, width, height, fill(), noFill(), stroke(), noStroke(), strokeWeight(), rectMode(), rect(), square(), ellipseMode(), ellipse(), circle(), line(), point(), triangle(), quad(), text(), and textSize(). Rectangles use a top-left position; by default, ellipses and circles use a center position. circle(x, y, diameter) takes a diameter, while canvas_studio.circle() takes a radius. rectMode() supports CORNER, CORNERS, CENTER, and RADIUS; ellipseMode() supports the same constants. Colors accept a named or hexadecimal color string (#RGB, #RGBA, #RRGGBB, or #RRGGBBAA) or grayscale, grayscale-alpha, RGB, and RGBA components; numeric channels are rounded and clamped to 0–255. Fill, stroke, stroke width, and text size remain active until changed. width and height report the current canvas dimensions. Unlike ordinary imported values, mouseX, mouseY, width, and height are live numeric-like values, so they also work with from processing_simulator import *. 

import processing_simulator as p

def setup():
    p.size(600, 300)

def draw():
    p.background(255)
    p.fill(255, 0, 0)
    p.noStroke()
    p.circle(p.mouseX, p.mouseY, 40)

# Start explicitly for desktop; the browser also supports this call.
p.start(draw, setup=setup)
from processing_simulator import *

def draw():
    background(240)
    circle(mouseX, mouseY, 40)

The helper is included in exported desktop ZIPs and generated viewer pages. On desktop, call p.start() with your callbacks. In the browser, you may also omit it and use the editor's automatic global callback registration.

Canvas and drawing

clear

studio.clear(color="#ffffff")

Fill the entire canvas with the given color.

background

studio.background(color)

Alias for clear(color).

rect

studio.rect(x, y, width, height, fill="#5b56e8", stroke="#000", *, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw a rectangle with separate fill and stroke colors. Set either color to None to omit it, or set stroke_width to control the outline thickness in pixels. By default, (x, y) is its top-left corner. Set origin=(0.5, 0.5) to place its center at (x, y); if rotate is set, it rotates around that point.

circle

studio.circle(x, y, radius, fill="#f6c85f", stroke="#000", *, stroke_width=1, rotation_origin=None, rotate=None, angle_unit="degrees")

Draw an anti-aliased circle with separate fill and stroke colors, centered at (x, y). Set either color to None to omit it, or set stroke_width to control outline thickness in pixels. Use normalized coordinates for rotation_origin; (0.5, 0.5) is its center.

ellipse

studio.ellipse(x, y, width, height, fill="#f6c85f", stroke="#000", *, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw an anti-aliased ellipse with separate fill and stroke colors, with its bounding box's top-left at (x, y) by default. Set either color to None to omit it, or set stroke_width to control outline thickness in pixels. Set origin=(0.5, 0.5) to place its center at (x, y); if rotate is set, it rotates around that point.

arc

studio.arc(x, y, radius, start_angle, end_angle, stroke="#000", width=2, *, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw a stroked arc with the diameter bounds' top-left at (x, y) by default. width controls stroke thickness in pixels. Set stroke=None to omit it. Set origin=(0.5, 0.5) to center it at (x, y). Arc angles increase clockwise; if rotate is set, the arc rotates around its origin point.

polygon

studio.polygon(points, fill="#5b56e8", stroke="#000", *, stroke_width=1, x=None, y=None, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw a polygon with separate fill and stroke colors from at least three (x, y) point pairs. Set either color to None to omit it, or set stroke_width to control outline thickness in pixels. Points stay at their supplied positions unless both optional x and y are given; then the default origin=(0, 0) (the bounding box's top-left) or the selected normalized origin is placed at that position. If rotate is set, the polygon rotates around that point.

line

studio.line(x1, y1, x2, y2, stroke="#000", width=2)

Draw a line between the two endpoint coordinates. width controls stroke thickness in pixels; set stroke=None to omit it.

text

studio.text(value, x, y, size=20, color="#253149", align="left", *, stroke=None, stroke_width=1, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw the string representation of value using its measured bounding box. Set color=None to omit the fill while retaining an optional outline; set stroke to a color to outline the text, and stroke_width to control outline thickness in pixels. Both fill and outline can be omitted by setting color=None and stroke=None. Set align to "left", "center", or "right" to align each line. The default origin=(0, 0) anchors the measured bounds' top-left at (x, y); if rotate is set, the text rotates around that point. Newline characters (\n) start a new line below the previous line.

Canvas size and transforms

set_canvas_size

studio.set_canvas_size(width, height)

Set the canvas pixel dimensions. Both values must be positive integers.

get_canvas_width

studio.get_canvas_width()

Return the current canvas width in pixels.

get_canvas_height

studio.get_canvas_height()

Return the current canvas height in pixels.

translate

studio.translate(x, y)

Move the origin for subsequent drawing operations by the given offset. Combine with rotate() and scale() to transform a group of shapes with one shared transform; this avoids setting up a separate rotation for each shape. Use reset_transform() afterward to restore the default transform.

rotate

studio.rotate(angle, angle_unit="degrees")

Rotate subsequent drawing clockwise. The angle unit may be "degrees" or "radians". For a group of shapes that share an angle and pivot, apply the rotation once with translate() and draw the shapes under that shared transform instead of passing origin and rotate to every shape.

scale

studio.scale(x, y=None)

Scale subsequent drawing horizontally by x and vertically by y. If y is omitted, both axes use x. Scaling, like translation and rotation, remains in effect for following shapes until reset_transform(); combine transforms once when drawing a group that shares them.

reset_transform

studio.reset_transform()

Reset translation, rotation, and scaling to their defaults.

hide_mouse_pointer

studio.hide_mouse_pointer()

Hide the mouse pointer while it is over the canvas. The pointer remains visible outside the canvas.

show_mouse_pointer

studio.show_mouse_pointer()

Show the mouse pointer while it is over the canvas.

Messaging between browser and desktop

connect

studio.connect(host, port, *, secure=False) -> CanvasConnection

Connect to the relay at host:port. The same port is used as the virtual service port registered by net_listen, so it is also the relay’s WebSocket listening port. Returns immediately; messages sent before the relay completes the connection are queued. Use connection.on_message(callback) to receive peer messages. Use secure=True when the relay endpoint is wss://.

net_listen (web runtime)

studio.net_listen(port, on_connected, *, relay_host="127.0.0.1", secure=False) -> CanvasListener

Register the virtual service on a relay running at relay_host:port. The same port is used by the real WebSocket relay; no extra relay port setting is needed. This does not bind an additional TCP port or expose the browser’s local IP address. By default the listener connects to a relay running on the same computer; remote clients pass the relay computer’s reachable hostname or IP to connect. A relay permits only one listener per virtual port at a time.

CanvasConnection.on_message

connection.on_message(callback)

Set the callback invoked with each JSON-decoded message from the paired peer. For accepted connections, register the callback inside on_connected. The connection’s relay-observed remote address and port are available in that callback.

CanvasConnection.get_remote_address

connection.get_remote_address()

Return the paired peer’s IP address as observed by the relay, or None until the virtual connection is established.

CanvasConnection.get_remote_port

connection.get_remote_port()

Return the paired peer’s source port as observed by the relay, or None until the virtual connection is established. These values describe the peer’s WebSocket endpoint as seen by the relay; NAT, proxies, and browser networking can affect them, and they are not a direct TCP connection between peers.

open_channel

studio.open_channel(name, on_message)

Open a local browser BroadcastChannel shared with tabs on the same origin. Use studio.net_listen() and studio.connect() for paired network connections. Older named-channel programs that pass server=... remain supported for compatibility.

connect_broadcast

studio.connect_broadcast(host, port, on_message, secure=False) -> CanvasChannel

Connect to the legacy relay broadcast service, which delivers each message to every other broadcast client. Use virtual connections for new applications.

CanvasConnection.send

connection.send(message)

Send a JSON-serializable value to the one peer paired with this connection.

connection.close

connection.close()

Close the virtual connection. A listener and its accepted connections are also closed when the program stops.

Virtual server example

import canvas_studio as studio

def connected(connection):
    print("Client address:", connection.get_remote_address())
    print("Client port:", connection.get_remote_port())
    connection.on_message(lambda message: print("Client:", message))
    connection.send({"text": "Connected"})

listener = studio.net_listen(8766, connected)

Virtual client example

import canvas_studio as studio

connection = studio.connect("192.168.1.20", 8766)
connection.on_message(lambda message: print("Server:", message))
connection.send({"text": "Hello"})

Start the relay on a reachable computer. Install its dependency with python -m pip install -r requirements-server.txt, then run python canvas_studio_server.py --host 0.0.0.0 --port 8766. Allow the port through that computer’s firewall. Desktop clients also need python -m pip install -r requirements-desktop.txt. Use the server computer’s LAN IP address (not 127.0.0.1 on other computers). This basic relay has no authentication or encryption; use it only on a trusted network unless protected by a secure, authenticated WebSocket proxy. 

# Legacy broadcast example. For point-to-point communication, use
# net_listen(port, on_connected) and connect(relay_host, port).
import canvas_studio as studio

SERVER_HOST = "192.168.1.20"
SERVER_PORT = 8766

def received(message):
    print("Received:", message)

connection = studio.connect_broadcast(SERVER_HOST, SERVER_PORT, received)

# Sender callback; use this in either runtime to send a message.
def mousePressed():
    connection.send({"text": "Hello from another program!"})

studio.start(mousePressed=mousePressed)

For local communication between browser tabs only, use studio.open_channel(name, on_message); both tabs must share the same origin. A browser page served over HTTPS needs a secure wss:// server endpoint.

Images

load_image

studio.load_image(name)

Load an image by filename from the Added Images gallery. Add the image to the project first.

image

studio.image(image_object, x, y, w, h, *, origin=(0, 0), rotate=None, angle_unit="degrees")

Draw a loaded image with its top-left at (x, y) by default, scaled to width w and height h. Set origin=(0.5, 0.5) to place its center at (x, y); if rotate is set, it rotates around that point.

Sounds

load_sound

studio.load_sound(name)

Load a sound by filename from the Added Sounds gallery. Add the sound to the project first.

play_sound

studio.play_sound(sound)

Play or resume a sound returned by load_sound(). Browsers may require the user to interact with the page before playback; call this from a mouse or keyboard callback to satisfy that requirement.

pause_sound

studio.pause_sound(sound)

Pause a sound returned by load_sound(). Use play_sound() to resume it.

stop_sound

studio.stop_sound(sound)

Stop a sound returned by load_sound() and reset its position to the beginning, so the next play_sound() starts from the beginning.

Frame callbacks

update

studio.start(draw, update=update)

Pass the optional game-logic callback as update to studio.start(); it runs before draw() on each display-paced frame.

draw

studio.start(draw)

Pass the drawing callback to studio.start() to invoke it on each display-paced animation frame. When both frame callbacks exist, update() runs first.

Input callbacks and values

mousePressed

studio.start(draw, mousePressed=mousePressed)

Pass this optional callback to studio.start() to handle a mouse button press on the canvas. Read studio.button during the callback for the button number: 0 is primary, 1 is middle, and 2 is secondary.

mouseReleased

studio.start(draw, mouseReleased=mouseReleased)

Pass this optional callback to studio.start() to handle a mouse button release. Read studio.button during the callback for the button number: 0 is primary, 1 is middle, and 2 is secondary.

button

studio.button

Mouse button number for the most recent mouse callback: 0 is primary, 1 is middle, and 2 is secondary. This follows the browser's MouseEvent.button numbering.

keyPressed

studio.start(draw, keyPressed=keyPressed)

Pass this optional callback to studio.start() to handle a key press while the canvas is focused. Holding a key does not repeat this callback.

keyReleased

studio.start(draw, keyReleased=keyReleased)

Pass this optional callback to studio.start() to handle a key release while the canvas is focused.

mouse_x and mouse_y

studio.mouse_x studio.mouse_y

Current pointer coordinates in canvas pixels. The origin is at the canvas’s top-left.

key

studio.key

String value of the most recent keyboard event, such as "Enter" or "a".

key_code

studio.key_code

Numeric key code for the most recent keyboard event; Enter is typically 13.

key_code_name

studio.key_code_name

Physical key identifier, such as "ShiftLeft" or "ShiftRight".

Example

import canvas_studio as studio

studio.set_canvas_size(800, 500)
player_x = 400

def update():
    global player_x
    if studio.key == "ArrowLeft":
        player_x -= 4
    if studio.key == "ArrowRight":
        player_x += 4

def draw():
    studio.clear("#ffffff")
    studio.circle(player_x, 250, 24, "#5b56e8")

studio.start(draw, update=update)
